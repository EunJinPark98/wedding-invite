# ✦ 별빛 초대장

**별처럼 빛나는 순간, 직접 만든 초대장으로 — 모바일 초대장 메이커**

결혼식 · 백일 · 돌잔치 · 칠순 · 팔순 · 생일까지,
디자인을 고르고 내용을 채우면 하나뿐인 모바일 초대장이 완성됩니다.
완성된 초대장은 고유 링크로 발급되어 카카오톡으로 바로 공유할 수 있어요.

## ✨ 주요 기능

- 🗂 **4가지 초대장 종류** — 결혼 청첩장 · 백일/돌잔치 · 칠순/팔순 잔치 · 생일
- 🎨 **종류별 전용 템플릿 24종** — 종류마다 6개씩, 디자인이 서로 완전히 다름
- 🖊️ **실시간 미리보기** — 입력하는 즉시 옆 초대장에 그대로 반영 (모바일은 우상단 미니 미리보기)
- 🎬 **인트로 연출 6종** — 초대장을 열 때 지나가는 첫 화면 (마지막 하나는 종류 전용)
- 🖼 **대표 사진 모션 4종** — 없음 · 줌 인 · 줌 아웃 · 아웃포커스
- 🔤 **한글 글꼴 9종 · 글자 크기 4단계 · 구분선 5종** — 제목/본문 글꼴을 따로 선택
- 📷 **사진 업로드** — 대표 사진 + 갤러리(최대 19장), 자동 압축 후 클라우드 저장
- ✋ **갤러리 드래그 정렬** — 손가락으로 꾹 눌러 순서 변경 (모바일 우선)
- 💾 **임시저장** — 쓰다 만 내용을 브라우저에 담아 두고 다음에 이어서 작성
- 📍 **네이버지도 · 카카오맵** — 장소 주소를 원하는 지도 앱으로 바로 열기 + 주소 복사
- 💳 **마음 전하실 곳** — 계좌 안내 (결혼은 신랑/신부측 구분, 생일은 숨김)
- 🙋 **주인공 소개** — 신랑·신부, 아기, 잔치 주인공을 이름 아래 몇 줄로 소개
- ⏱️ **디데이 카운트다운** — 남은 일/시/분/초 실시간 표시
- 🔗 **공유 링크 발급** — `/v/abc12345` 짧은 링크 + 카톡 공유 카드(OG 미리보기)
- 🔐 **카카오 · 네이버 로그인** — 만든 초대장을 언제든 수정·삭제, 회원 탈퇴까지
- 🧹 **자동 정리** — 행사 다음 날 링크와 사진까지 완전 삭제
- 📱 **모바일 최적화** — 하객은 앱 설치 없이 링크만 열면 끝

## 🔐 계정 · 데이터 수명

이 서비스는 **개인 사진과 가족 정보를 다루기 때문에** 보관 기간을 짧게 잡았습니다.

| 항목 | 정책 |
|---|---|
| 로그인 | 카카오 · 네이버 (Supabase Auth) |
| 세션 | 브라우저를 닫거나 **24시간**이 지나면 자동 로그아웃 |
| 제작 한도 | **종류마다 1개씩, 계정당 최대 4개** |
| 행사 날짜 | **오늘 이후**만 선택 가능 (입력·저장·서버에서 각각 검사) |
| 게시 기간 | 행사 **당일까지** 공개 (직접 고르지 않고 행사 날짜로 자동 결정) |
| 자동 삭제 | 행사 **다음 날 0시(KST)** 부터 비공개, **00:30** 에 DB 행과 사진까지 완전 삭제 |
| 회원 탈퇴 | 마이페이지에서 직접 — 초대장·사진·계정을 한 번에 삭제 |

- 만료된 초대장은 종류 한도에서 빠지므로, 삭제를 기다리지 않고 같은 종류를 새로 만들 수 있어요.
- 초대장을 직접 삭제하거나 사진을 교체하면, 쓰이지 않게 된 사진도 Storage에서 함께 정리됩니다.
- 만들다 그만둬서 어느 초대장에도 딸리지 않은 사진은 하루가 지난 뒤 함께 정리됩니다.
- 정리 작업은 매일 00:30(KST)에 도는 Vercel Cron(`/api/cron/purge`)이 수행합니다.
- 초대장 페이지는 검색엔진에 올라가지 않습니다(`noindex`). 링크를 아는 사람만 볼 수 있어요.
- 문서: [이용약관](https://starinvite.vercel.app/terms) · [개인정보처리방침](https://starinvite.vercel.app/privacy)

> ⚠️ 삭제는 **복구할 수 없습니다.** 사용자에게도 에디터와 마이페이지에서 안내하고 있어요.

## 🛡 운영 화면 (`/pej`)

`ADMIN_EMAILS` 에 적힌 계정으로 로그인했을 때만 열리는 운영 현황 화면입니다.
그 외에는 주소를 알아도 **없는 페이지(404)** 로 보입니다.

- 가입한 계정 수 · 만든 초대장 수 · 게시 종료 건수 + 종류별 통계
- 계정 목록(10개씩 페이징 · 이름 검색)과 그 계정이 만든 초대장 바로 열기
- 계정 삭제 — 초대장·사진까지 함께 지우고, `KAKAO_ADMIN_KEY` 가 있으면 카카오 연결도 끊습니다
- 어느 초대장에도 딸리지 않은 사진 정리 버튼

> 초대장 테이블은 RLS로 잠겨 있어, 목록을 통째로 가져가는 건 서버(서비스 키)에서만 가능합니다.

## 🛠 기술 스택

- **프레임워크** — Next.js 16 (App Router · Turbopack), React 19, TypeScript
- **스타일** — Tailwind CSS v4, next/font (한글 웹폰트), CSS 애니메이션

## ☁️ 배포 (Supabase + Vercel)

<details>
<summary><b>1. Supabase 프로젝트 연결</b></summary>

1. [supabase.com](https://supabase.com) 에서 프로젝트 생성
2. `supabase/schema.sql` 내용을 **SQL Editor** 에 붙여넣고 실행
   → `invitations` 테이블 + 공개 Storage 버킷 `photos` + 정책이 한 번에 생성됩니다
3. 이미 예전 스키마로 만들어 둔 프로젝트라면 `supabase/2026-08-tighten-rls.sql` 도 실행
   → 누구나 목록을 읽거나 쓸 수 있던 정책을 걷어냅니다
4. `.env.local.example` → `.env.local` 로 복사하고 값 채우기
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` (Settings → API)
   - `SUPABASE_SERVICE_ROLE_KEY` — 저장·삭제·네이버 로그인에 필요 (RLS 우회, 서버 전용)
5. `npm run dev` 재시작

</details>

<details>
<summary><b>2. 소셜 로그인 설정</b></summary>

**카카오** — Supabase 대시보드 → Authentication → Providers → Kakao
[developers.kakao.com](https://developers.kakao.com) 에서 앱 생성 후 REST API 키/Secret 입력
동의항목에서 **닉네임 · 이메일**을 받도록 설정해 두면 마이페이지·운영 화면에서 계정을 알아볼 수 있습니다.

**네이버** — Supabase가 기본 제공하지 않아 커스텀 플로우로 처리합니다
[developers.naver.com](https://developers.naver.com) 에서 앱 등록 후 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 설정
Callback URL: `{사이트주소}/api/auth/naver/callback`
검수 신청 시 이용약관·개인정보처리방침 주소로 `/terms`, `/privacy` 를 제출하면 됩니다.

**카카오톡 공유** — 앱의 JavaScript 키를 `NEXT_PUBLIC_KAKAO_JS_KEY` 에 설정
[앱] → [제품 링크 관리] → [웹 도메인] 에 사이트 주소 등록 필요

</details>

<details>
<summary><b>3. 환경변수</b></summary>

| 이름 | 필수 | 용도 |
|---|:---:|---|
| `NEXT_PUBLIC_SUPABASE_URL` | ✔ | Supabase 프로젝트 주소 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ✔ | 브라우저에서 쓰는 공개 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | ✔ | 서버 전용 — 저장·삭제·네이버 로그인 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | | 네이버 로그인 |
| `NEXT_PUBLIC_KAKAO_JS_KEY` | | 카카오톡 공유 버튼 |
| `CRON_SECRET` | ✔ | 만료 초대장 정리 작업 인증 토큰 |
| `ADMIN_EMAILS` | | `/pej` 에 들어올 수 있는 이메일(쉼표로 여러 개) |
| `KAKAO_ADMIN_KEY` | | 탈퇴 시 카카오 연결까지 끊기 |
| `NEXT_PUBLIC_SITE_URL` | | 공유 카드·robots·sitemap 의 기준 주소 |

</details>

<details>
<summary><b>4. Vercel 배포</b></summary>

1. GitHub 레포 import
2. **Settings → Environment Variables** 에 위 값들을 등록
3. **`CRON_SECRET` 을 반드시 추가** — 만료 초대장 정리 작업의 인증 토큰
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
   ```
   미설정 시 `/api/cron/purge` 는 503으로 거부되어 정리가 실행되지 않습니다
4. **Deploy** → `https://your-app.vercel.app` 발급
5. **Cron Jobs** 탭에서 `/api/cron/purge` 가 매일 등록됐는지 확인
   (Hobby 요금제는 지정한 시각 언저리에 도는 유연한 스케줄입니다)
6. 이후 `git push` 하면 **자동 재배포**

> 환경변수는 저장만으로 적용되지 않고 **재배포해야** 반영됩니다.

</details>
